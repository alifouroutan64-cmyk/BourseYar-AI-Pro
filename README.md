# بورس‌یار AI Pro

نسخه اولیه اپ اندرویدی بورس‌یار.

## ساخت APK با GitHub Actions

1. وارد تب **Actions** مخزن شوید.
2. Workflow با نام **Android APK build** را انتخاب کنید.
3. روی **Run workflow** بزنید.
4. پس از پایان موفق، فایل APK در بخش Artifacts با نام `BourseYar-debug-apk` قابل دانلود است.


## وضعیت این نسخه
- رابط فارسی RTL
- دکمه دریافت داده بازار
- درخواست آزمایشی به endpoint غیررسمی TSETMC و نمایش پاسخ خام
- هنوز parser داده، تحلیل تکنیکال/بنیادی، رنکو و سیگنال تأییدشده پیاده‌سازی نشده‌اند.

**این نسخه صرفاً scaffold آزمایشی است؛ قبل از معامله، API و داده‌ها باید اعتبارسنجی شوند.**
